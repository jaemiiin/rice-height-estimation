# Original RGB images

All 92 unchanged JPEGs are available in the [complete study-data ZIP](https://github.com/jaemiiin/rice-height-estimation/releases/download/data-v1.0.0/rice-height-study-data-v1.0.0.zip). Run `python tools/download_data.py` from the repository root to download, verify and install them under `<Region>/<original filename>.jpg`.

The 92 original byte hashes match `../metadata/raw_image_manifest.csv`. The repository owner has confirmed publication permission. Raw images remain excluded from Git history because they are distributed as a versioned Release asset, not because permission is pending. The full ZIP also contains the 122 tabular/metadata/result files committed in Git.
