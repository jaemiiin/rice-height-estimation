# Public release scope

The repository now distributes both code and approved research data. The earlier code-only release is preserved in Git history. The owner subsequently confirmed all data and code publication permissions and requested the release of the 214 previously withheld study files.

See [DATA_RELEASE.md](DATA_RELEASE.md) for the data selection, download, checksums and reproduction instructions. All 122 metadata/feature/result files are included in Git; the complete Release ZIP adds the 92 original RGB images and also contains those 122 files. No study file in the reviewed 214-file set remains excluded.

Numerical research code, original input bytes and manuscript files are unchanged. Aggregate and detailed reference results are public. Full local fitting caches, transient logs, virtual environments and private preparation snapshots remain excluded because they are unnecessary for reproducing the documented analyses. The old `provenance/data_permission_pending.csv` is a local historical record superseded by public `provenance/data_files.json`.

Publication authorization was confirmed by the repository owner. A general reuse license and manuscript/dataset DOI have not been assigned; no new license or persistent-identifier record is invented here. Historical validation files describing the earlier code-only checkout remain explicitly historical; the current data release is described separately.
